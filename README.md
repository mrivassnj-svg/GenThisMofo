# THE ONLY PROJECT GUIDELINES:

## AND ALSO Quick Note Before You Start,

I built this project as something you can **use, change, break, rebuild, and make your own**.

I'm sharing it in the spirit of open source because I think that is one of the best ways to learn. You should be able to look at what someone else created, figure out how it works, change the parts you don't like, and eventually build something better from it.

> **Knowledge doesn't do much good if we keep it to ourselves.**

So don't feel like you have to preserve everything exactly the way I made it. Take the ideas, experiment with them, and see where you can take them.

---

# How To Blast Off

## 1. Open Google Colab

Start by opening the `.ipynb` file I provided in **Google Colab**.

Once the notebook loads, take a minute to look through the sections before running everything.

Each project is organized a little differently, so don't assume every notebook works exactly the same way.

---

## 2. Find the AI Generation Prompt

Look for the section labeled:

> **AI Generation Prompt (Copy to Midjourney/DALL-E)**

This section contains the prompt used to create the diagram for that particular project.

Copy the prompt and paste it into the image-generation tool you want to use, such as Midjourney or DALL-E.

---

## 3. Generate Your Diagram

Generate the image using the provided prompt.

You don't necessarily have to stop there, either. If you want to experiment with the prompt, go for it.

Try changing things like:

- Layout
- Labels
- Visual style
- Colors
- Level of detail
- Organization of the diagram

The goal is to understand how the prompt affects the result.

---

## 4. Save the Image

Once you have an image you are happy with, save it to your computer.

Keep the filename **simple** and make sure you know where you saved it.
